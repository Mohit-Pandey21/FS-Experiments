# 📱 Social Media Post Composer

A modern **React + Vite** application that allows users to compose social media posts for multiple platforms. The app provides platform-specific character limits, image upload with preview, emoji support, and automatically saves drafts using Local Storage.

## ✨ Features

* 📝 Create posts for multiple platforms

  * LinkedIn
  * X (Twitter)
  * Instagram
* 📊 Live character count with platform-specific limits
* 😀 Emoji picker
* 🖼️ Image upload with preview
* 💾 Automatic draft saving using Local Storage
* 📱 Responsive and modern UI
* 🎨 Built with Tailwind CSS

## 🚀 Installation

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project folder

```bash
cd my_react_app
```

### 3. Install dependencies

```bash
npm install
```

If needed, install the additional libraries:

```bash
npm install react-icons lucide-react emoji-picker-react
```

### 4. Start the development server

```bash
npm run dev
```

Open the URL displayed in the terminal (usually `http://localhost:5173`).

## 💡 How It Works

1. Enter your post in the text area.
2. Select the target social media platform.
3. The application updates the character limit based on the selected platform.
4. Add emojis using the emoji picker.
5. Upload an image and preview it before publishing.
6. Your draft is automatically saved in Local Storage.
7. Click **Publish Post** to submit the post and clear the saved draft.
